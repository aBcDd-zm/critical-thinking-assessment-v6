# V6.2.3 自然承接语气候选

## 目标与非目标

`natural_interviewer_v6.2.3` 是从 v6.2.1 完整继承的显式候选，用于降低脆弱话题下连续裸问带来的生硬感，并防止正常访谈回合只有陈述而没有清晰问题。它不是心理咨询模式，不会诊断、无依据断言或替参与者确定情绪与关系真相，也不改变六维测量、评分、来源归属或报告。

## 可见表达变化

- 对方明确说出痛苦、哭泣、失落、害怕、不安、受伤或被背叛等脆弱经历时，先使用一句有其原话依据、温和克制的承接，再自然进入一个问题。
- 情绪只是推测时必须使用“似乎”“可能”等试探语气；不替参与者确定情绪、动机、关系或心理状态。
- 尚未建立可定位事件时，先使用保留选择权的邀请，再请对方从最近一次真实经历说起；不连续使用“为什么”“哪些具体事情”“最难判断的是什么”这类裸问。
- 正常探查恰好保留一个明确、开放的问题。对方整句正在纠正误解、拒答单题或设定边界、说明没听懂、要求暂停时，可以 `continue` 而不附加新问题；明确要求结束本次访谈、停止回答或生成报告时，必须返回 `finish/user_requested`。

## 不变合同

v6.2.1 的决策主线、精确 user span anchor、`navigation`、来源澄清、`enforce` 归属、安全门、最低 8 次保护线、40 次技术上限、readiness、用户确认结束、报告与 PDF 均保持不变。每个会话继续按开场 trace 绑定 Prompt 与归属模式，配置切换只影响新会话。

## 发布边界

代码、开发示例和生产样例默认仍为 `v6.2.1 + enforce`。v6.2.3 只能以 `NATURAL_INTERVIEWER_PROMPT_VERSION=v6.2.3` 与 `EVIDENCE_ATTRIBUTION_MODE=enforce` 显式启用；创建、推送或合并候选 PR 本身不会切换生产。启用前需先完成 v6.2.1/v6.2.3 同场景真实 DeepSeek 匿名对照、人工语气验收与本地完整流程验收。

## 验收口径

候选专项自动化冻结 v6.2.1 与 v6.2.3 哈希，直接覆盖正常单问题、脆弱承接、纠正与边界、来源澄清和明确结束合同；共享 v6.2 流程回归覆盖 navigation/anchor、安全、快照、报告、40 次技术上限与会话版本绑定。真实对照只使用合成场景与仓库外私有输出，不读取参与者数据；人工盲评至少检查温和、真人感、非审问感、证据克制、事件锚定、信息增量、边界修复、继续表达意愿与单问题安全。该对照是发布门禁，不能当作标准化效度或人群效果证明。

## 2026-08-09 真实 DeepSeek 匿名对照

最终可裁决运行完成 96 个合成逻辑调用，共观察到 97 次物理请求；48 个 v6.2.3 调用中有 1 次合同修复。运行时非劣门通过：v6.2.3 修复率 2.08%，平均尝试数 1.0208，p95 延迟 2112.9 ms；v6.2.1 分别为 0%、1.0 和 1932.1 ms。

两名不知版本映射的评审完成 16 组场景盲评。两版均无严重断裂、过度推断、结构、主线或边界回归。但 v6.2.3 在目标四项（温和度、真人感、非审问感、继续表达意愿）的平均组合差值为 -0.1641；匿名偏好票为 v6.2.1 17 票、v6.2.3 14 票、平局 1 票。因此此轮正式裁决为 `KEEP_V621`，v6.2.3 不具备替换默认版的证据。Draft PR 和本地体验只用于收集进一步人工反馈，不应被合并、激活或部署，除非新一轮证据改变该结论。
