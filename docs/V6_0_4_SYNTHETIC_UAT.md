## 目的与边界

本轮只验证对话表达层的自然度收尾与共情保真，并验证被试端语音输入可由前端开关隐藏。没有修改评分规则、报告逻辑、访谈结束逻辑、研究证据或后端语音输入合同。

所有真实模型调用均使用不含个人数据的合成情境。测试不读取应用数据库，不使用真实被试数据，不执行自动评分，也不构成正式效度、信度或被试体验结论。

## 对照协议

- 8 类合成情境：事实与决策、情绪与压力、明确纠错、请求解释、明确不确定、长回答与多方权衡、成熟方案但缺少条件、拒答与话题转移。
- 每个情境同时生成 v6.0.3 与 v6.0.4 两臂，每臂 3 个连续回合。
- 共 48 个逻辑调用；发生 6 次受限传输重试，共 54 个物理 API 请求，低于 80 次硬上限。
- API 原始 `model` 字段 54/54 均严格等于 `deepseek-v4-flash`；HTTP 请求 54/54 成功；未使用 JSON 修复调用。
- 候选包仅含 opaque case/candidate id；版本映射保存在独立 sealed 文件中，盲审完成后才解盲。
- 私有运行目录权限为 `0700`，文件权限为 `0600`。

## 双盲人工审核结论

两名独立审阅者只查看匿名候选正文。两人均未发现严重共情退化、严重追问回归，也未发现同一类严重问题在两个独立场景复现，因此没有触发停止条件。

解盲后的偏好结果并不一致：

- 审阅者 1：v6.0.4 为 6/8，v6.0.3 为 2/8。
- 审阅者 2：v6.0.4 为 2/8，v6.0.3 为 5/8，另有 1/8 平局。

这组小样本不能证明 v6.0.4 整体优于 v6.0.3。它只支持以下较窄结论：v6.0.4 未出现协议定义的严重回归，可以作为保留回退开关的候选版进入代码审查。

## 已知残余问题

- 部分候选仍出现“你提到／你说＋复述＋追问”或“嗯＋承接”的轻中度模板痕迹。
- 一个澄清情境的 v6.0.4 首回合出现两个主问题；下一回合主动致歉并收束为单问题。该问题未跨第二个独立场景复现。
- 温暖感与信息增量之间仍有个体偏好差异；少数更直接的回复信息价值较高，但主观上可能略显工具化。
- 自动审计标签依赖有限正则表达式，对不同开场词并不完全对称，只用于定位人工复核，不用于版本胜负或研究结论。
- 延迟受随机生成顺序、网络状态和传输重试影响，本轮不能据此归因于某一 Prompt 版本。

## 发布判定

本轮判定为 **Draft PR 可审查，尚未批准合并或部署**。默认版本可以通过配置选择 v6.0.4，并可立即回退至完整保留的 v6.0.3。正式被试发布前仍应由项目成员确认部署配置、完成目标环境冒烟，并在研究数据中记录实际使用的 Prompt 版本。
