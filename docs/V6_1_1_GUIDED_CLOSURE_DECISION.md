## 当前决定

v6.1.1 只登记为待验收候选，不改变默认版本，也不代表已获准部署。候选组合包括版本化访谈 Prompt、模型结束意图到服务端有效动作的映射、对应 SSE/恢复快照，以及用户接受最新建议的 API：

- 开场邀请用户选择最近一件真实、具体、需要认真判断或权衡的事情，不使用“想说什么都可以”的自由闲聊邀请。
- 后续默认沿同一真实事件柔性深入；泛泛琐事、抱怨或原则缺少可定位经历时，温和回到一个具体事件；跑题时在一轮内拉回。正常探查通常为 1—2 句话、35—90 个汉字，最多一个主要问题。
- `finish/enough_understanding|natural_closure` 只表达结束建议意图；服务端对 v6.1.1 或已接受新版“用户确认结束”说明的会话把它映射为 `suggest_finish`，并把参与者可见文案确定性归一为明确“仍可继续补充”的建议，发出 `session_closure_suggested` 并保持会话可继续。
- 用户可以继续回答并使旧建议失效，也可通过带建议 turn ID 和 transcript 指纹的接受接口确认结束。
- 只有用户明确要求结束本次访谈、停止继续回答或生成本次报告时，模型才可返回终局 `finish/user_requested`；事件、项目或方案本身“结束”的叙述不属于该意图。

本候选不增加固定轮次、题库、阶段、维度 coverage 或服务端下一题控制，也不修改终评、报告算法、模型 thinking、token、timeout 或 retry 配置。每个会话按开场 trace 绑定 Prompt 版本，避免发布切换或回滚使进行中会话中途换版。它扩展 API 与会话动作语义，但复用既有 turn、trace 和 transcript 指纹，不新增数据库字段或 schema migration。

## 去标识化只读基线

本节只记录后台只读审计提供的聚合数字，不包含参与者原话、昵称或其他直接标识符。

- 审计覆盖 166 个会话，其中 75 个为已完成会话。
- 75 个已完成会话的用户回答数：最小值 0、P25 为 3、中位数 6、P75 为 10、最大值 26。
- 75 个已完成会话中，34 个在不超过 5 次用户回答时完成，52 个在不超过 8 次用户回答时完成。
- 75 个已完成会话中，64 个被标记为建议人工复核。
- 在 24 份分层抽取的已完成样本中，复现 1 份在 5 次用户回答后以 `natural_closure` 结束且六维均无证据的会话，以及 1 份在 6 次用户回答后以 `enough_understanding` 结束的会话；多数短会话由用户主动结束。

## 解释限制

- 24 份样本是为审计而作的分层、非随机抽取，不代表总体发生率，也不能用于估计 v6.1.1 的效果。
- 上述数字来自现有版本的观察性快照，没有随机分配、同期对照或混杂控制，不能据此推断 Prompt 与结束轮次、证据充分度或人工复核之间的因果关系。
- “建议人工复核”是现有证据规则产生的审计标记，不等同于报告错误，也不是参与者能力结论。
- 该基线只用于冻结问题背景和后续验收指标；不得把它写成 v6.1.1 已经改善自然度、测量质量或科学效度的证据。

## 候选验收门

在任何默认版本或生产配置切换前，至少完成：

1. 自动化固定旧版 Prompt 哈希、v6.1.1 哈希、默认仍为 v6.0.5，以及候选的真实事件开场、同事件主线和结束确认语义。
2. 使用不含真实被试数据的合成场景覆盖：泛泛工作琐事、纯抱怨、多个话题、跑题、完整方案、表达不确定、明确要求结束，以及模型试图以 `natural_closure` 或 `enough_understanding` 结束。
3. 完成 v6.0.5 与 v6.1.1 的匿名真实模型对照，由至少两名不知道版本映射的评审者独立评价具体事件建立、同事件连续性、跑题拉回、非诱导性、自然度与继续表达意愿。
4. 单独统计结束原因与用户回答数分布、证据有限/未充分测得比例、人工复核建议比例、用户主动结束比例和技术失败；阈值必须在查看候选结果前冻结。
5. 验证 `suggest_finish`、`session_closure_suggested`、恢复快照、继续回答使旧建议失效、带 turn ID 与 transcript 指纹的接受接口、陈旧建议拒绝及幂等重试；同时确认无数据库 schema migration，终评 rubric、12000-token 上限与单次 90 秒模型超时不变，所有失败共享最多一次重试，并且同步评分路由具备覆盖两次模型尝试的 200 秒代理预算。

通过上述门槛仍只能支持一次受控发布决定，不能证明心理测量效度、科学有效性或相对总体优越性。回滚 Prompt 时将 `NATURAL_INTERVIEWER_PROMPT_VERSION` 改回 `v6.0.5` 并记录实际使用版本；该操作只影响新会话，且不撤回已在开始页向用户承诺的确认结束语义。
