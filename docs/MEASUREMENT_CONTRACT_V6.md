# 思衡 V6 六维证据合同

## 适用边界

V6 的六维是对一次自然对话的**后置证据整理框架**，不是访谈导航器。访谈官不会因“缺哪一维”而突然换题、补题或延长对话；用户无需完成固定话题、阶段、题库或六维轮询。V6.1 另设 40 个有效回答的数据完整性门槛和 45 个有效回答的技术硬上限，但该门禁不选择问题内容或顺序，也不保证每一维都被测得。达到结束资格后，访谈官仍依据逐字稿自行判断是否自然收束。

该结果不是标准化心理测验。它不得用于跨人、跨议题、跨时间排名、人格判断、职业/留学建议或替用户作决定。

## 固定观察视角

| key | 名称 | 可观察的用户行为 |
| --- | --- | --- |
| `problem_definition` | 问题界定 | 区分现象与待决定问题，说明目标、边界、约束、相关方或时限。 |
| `evidence_evaluation` | 证据评估 | 区分已知/未知与事实/假设，说明来源、可靠性、核验或改变判断的证据。 |
| `reasoning_argumentation` | 推理论证 | 说明理由、前提、推导、替代解释、反例或关键假设。 |
| `multiple_perspectives` | 多元视角 | 比较不同相关方、价值冲突、风险承担或短长期影响。 |
| `integrative_decision` | 整合决策 | 把判断转为可执行的下一步、取舍、优先级、责任、时点或备选。 |
| `dynamic_adjustment` | 动态调整 | 说明什么新信息、条件或反馈会使其调整、坚持或复盘。 |

维度定义固定；V6 允许议题和对话走向因人而异，但不允许按议题改写维度含义或把未谈及的维度视为低能力。

## 访谈期禁止的测量调度

访谈请求不得携带或由服务端推导：`target_dimension`、`coverage`、`coverage_ceiling`、`dimension_followups`、固定阶段、候选题库、反事实必答、最终整合必答或六维轮询。允许的 `completion_gate` 仅描述有效回答数、40/45 边界和是否可结束；它不得包含下一题、目标维度或内容路由。质量标记可用于后续人工审计，不能重写自然问法或指挥下一题。

## 终评与证据门槛

冻结逐字稿后，独立评分器对每一维输出：

```json
{
  "dimension_key": "evidence_evaluation",
  "score": 1,
  "sufficient": true,
  "quotes": [{ "turn_index": 3, "quote": "用户原话的连续片段" }],
  "reason": "基于原话的简短解释",
  "confidence": 0.0
}
```

`score` 只能为 1–5 整数或 `null`。数字分数必须同时满足：

1. 至少一条 quote 指向某个用户 turn，且为该 turn 的连续精确子串；
2. 评分器将该维判为 `sufficient=true`；
3. 原话呈现的是相关的可观察思维/决策行为，而不仅是访谈官提示、用户自评标签或一句“我很擅长/不擅长”。

评分器还必须逐维输出 `opportunity_observed`。只有访谈直接引出或用户实质回应该维度的可观察行为时才为 `true`；未触及、沉默、泛化短答或仅有自我标签时为 `false`。没有观察机会时必须 `score=null`，绝不能以 1 分代替“没有测到”。有观察机会但仍不足以支持等级时映射为 `limited`，没有机会时映射为 `unmeasured`。

任何条件失败时，`score=null`。AI 的总结、暗示、问题、系统事件、Prompt、模型自行概括或用户自我标签本身都不能成为能力证据。引用无效、诱导污染、评分格式修复、低置信度或缺维均应触发人工复核建议。

用户端状态映射为：

- `sufficient`：证据充分，可显示分值和对应原话。
- `limited`：有相关表达但不足以支持数字分数，显示“证据有限”。
- `unmeasured`：本次对话未充分触及，显示“未充分测得”。

未校准 `confidence` 只保留在本地复核台，绝不显示为用户端数字结论。

## 报告表达

报告可以列出六维、可核验原话、本次观察、优势、可继续思考的方向和实验性边界。参与者报告不生成综合总分；证据充分的单个维度只展示 1–5 序数等级，不换算成未经校准的 20–100 百分制。1–3 级不得包装为“优势”，只有 4–5 级可使用优势标签。未测得维度不按 0 或 1 分计入任何汇总，而是按逐维观察机会显示“证据有限”或“未充分测得”。不得输出人格结论、职业/留学排名或替用户选择。建议不得伪装成测量证据，也不得把未测得说成低分。
