# V6 五级评分标准

版本：`agent_test_v2_five_level`

本文件沿用上一版六维 Rubric 的五级行为锚点，作为 V6 终评器的评分标准。评分对象是用户在本次冻结逐字稿中实际表现出的可观察行为，不是表达长度、语气、专业术语或方案偏好。

## 通用规则

| 分数 | 含义 |
| ---: | --- |
| 1 | 明确低水平，主要停留在复述、表态、单点判断或无依据结论。 |
| 2 | 出现零散有效要素，但关键部分缺失，尚未形成基本完整表现。 |
| 3 | 达到基本可识别表现，但深度、完整性或连接性有限。 |
| 4 | 表现系统、清晰且大部分完整，但仍有一个实质性缺口。 |
| 5 | 表现完整、可验证，能够处理复杂性并说明边界。 |

`IE`（`score=null`）不属于分数等级。未作答、跑题、技术截断、无关复制，或该维度没有基本展示机会时使用 `IE`，不得因为证据不足记为 1 分。

## 六维行为锚点

### 问题界定 `problem_definition`

| 分数 | 行为标准 |
| ---: | --- |
| 1 | 主要复述情境或直接表态，缺少清晰的问题界定。 |
| 2 | 能指出一个局部问题，但未区分表面现象与核心矛盾，问题边界、约束和受影响对象大多缺失。 |
| 3 | 能指出主要问题，但对边界、约束或利益相关方说明不完整。 |
| 4 | 能清楚界定核心问题及主要边界，说明关键约束和相关方影响，但问题层级、优先关系或次要边界仍有遗漏。 |
| 5 | 能清楚界定核心问题、边界条件、约束和相关方影响，并说明问题之间的层级关系。 |

无效高水平证据：只复述题目背景、直接给出结论、只表达个人偏好。

### 证据评估 `evidence_evaluation`

| 分数 | 行为标准 |
| ---: | --- |
| 1 | 直接接受已有信息，缺少对来源、可靠性和局限的判断。 |
| 2 | 意识到需要核实信息或查看数据，但没有明确评价标准、来源质量或可执行的验证方法。 |
| 3 | 能提出部分证据依据，但对证据质量、样本和偏差分析有限。 |
| 4 | 能从来源、样本、可比性、可靠性或局限中的多个方面评价证据，并采用至少一种交叉核验，但对潜在偏差或不确定性说明仍不完整。 |
| 5 | 能系统评估证据来源、样本、相关性、可靠性和局限，并提出交叉验证方式。 |

无效高水平证据：只引用单一数据、只凭权威意见或情绪判断。

### 推理与论证 `reasoning_argumentation`

| 分数 | 行为标准 |
| ---: | --- |
| 1 | 结论跳跃，缺少清楚的推理过程。 |
| 2 | 能给出一个理由或简单条件判断，但关键前提、证据与结论之间的关系大多未说明。 |
| 3 | 有基本推理，但前提、证据或假设说明不够完整。 |
| 4 | 推理链较完整，能说明主要前提、条件和风险，并考虑反例或验证方式，但对替代解释或部分隐含假设处理不够充分。 |
| 5 | 能构建完整推理链，主动说明关键假设、可能反例和验证方式。 |

无效高水平证据：只有结论、口号式理由或经验判断，缺少证据到结论的推理链。

### 多元视角 `multiple_perspectives`

| 分数 | 行为标准 |
| ---: | --- |
| 1 | 只从单一视角看问题，忽略其他相关方。 |
| 2 | 能意识到不止一个相关方，但主要停留在列举角色，缺少对诉求、风险和冲突的比较。 |
| 3 | 能提到多个视角，但比较和权衡不充分。 |
| 4 | 能比较多方诉求、利益冲突、短长期影响或风险分担，并提出基本权衡原则，但实际协调或缓解方案仍不完整。 |
| 5 | 能整合多方视角，分析利益冲突、风险分担和价值取舍。 |

无效高水平证据：只从单一部门或个人便利出发。

### 整合决策 `integrative_decision`

| 分数 | 行为标准 |
| ---: | --- |
| 1 | 决策笼统，缺少取舍依据和执行条件。 |
| 2 | 能给出明确方向和至少一个行动，但缺少优先级、责任分工、执行条件或风险控制。 |
| 3 | 能提出方案，但执行条件、风险控制或备选路径不完整。 |
| 4 | 方案包含明确优先级、责任分工、执行顺序、主要风险控制和条件性备选路径，但监测闭环或协同细节仍不完整。 |
| 5 | 能形成综合方案，说明优先级、触发条件、责任分工、风险控制和备选方案。 |

无效高水平证据：只有态度或原则，没有执行步骤、边界条件和风险控制。

### 动态调整 `dynamic_adjustment`

| 分数 | 行为标准 |
| ---: | --- |
| 1 | 面对新信息仍坚持原判断，或改变判断但没有理由。 |
| 2 | 能承认新信息需要调整，并提出笼统变化，但没有说明影响程度、触发条件或后续验证。 |
| 3 | 能部分调整判断，但对调整幅度、依据和后续策略说明不足。 |
| 4 | 能根据新证据调整范围或路径，说明调整依据、触发阈值和后续监测，但调整边界或回退机制仍不完整。 |
| 5 | 能基于新证据清楚调整判断、方案和后续监控策略，并说明调整边界。 |

无效高水平证据：面对新信息仍机械坚持原结论，或频繁改变立场但没有解释理由。

## 终评执行边界

- 先找用户原话，再匹配行为锚点；访谈者的话、模型总结和用户自我标签不能作为能力证据。
- 同一句话可以支持不同维度，但不能因为重复出现或同时关联多个维度自动加分。
- 4–5 分必须有原话明确呈现对应锚点；没有达到该锚点时选择更低等级。
- 证据不足输出 `IE`，不补问、不把 `IE` 转成低分。
