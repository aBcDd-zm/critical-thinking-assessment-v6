验收候选：`natural_interviewer_v6.0.5`

回退版本：`natural_interviewer_v6.0.4` 与 `natural_interviewer_v6.0.3`

## 修订边界

本轮只修订自然访谈 Prompt 的对话策略：保留并强化有来源支持的人本主义共情、温暖感、真人感、节奏尊重、试探性理解、纠错优先和关系修复；去除的只是无信息功能的机械复述、固定“表示理解”以及连续同形的“承接—追问”结构。

对话策略修订本身没有修改评分规则、报告逻辑、六维合同、访谈框架、前端或已有研究证据。没有引入固定题库、固定阶段、六维轮询、确定性改写或第二模型润色。

同一交付分支另包含一项相互独立的技术上限体验补充：会话达到既有 40 次技术保护上限时，前端明确说明此前回答已保存、该状态不代表证据已充分，并引导用户结束访谈和生成报告；这项补充不改变上限数值、结束判断、评分或报告逻辑。

## 合成对照协议

- 10 类非个人合成情境：明确情绪与失去、中性事实与决策、纠正与关系修复、困惑与解释、隐私边界与话题切换、暂停与无问题回应、简短回答后的具体化、长文本多焦点、明确不确定、重复噪声输入。
- 每个情境同时生成 v6.0.4 与 v6.0.5 两个匿名候选，每臂最多 3 个连续回合。
- 计划 60 个逻辑调用；其中一个候选在第 2 回合因用户明确请求暂停而正常结束，因此实际完成 59 个逻辑调用。
- 共 71 个物理 API 请求，低于 80 次硬上限；71/71 均为 HTTP 200，API 原始 `model` 均为 `deepseek-v4-flash`。
- 未读取应用数据库，未使用真实被试数据，未使用模型评审或自动评分。
- 私有运行目录为 `0700`，评审、审计和 sealed 文件均为 `0600`，且位于仓库外。

## 双人独立盲评与决策门禁

两名独立评审只查看匿名候选包，在冻结评分文件前未接触版本映射。冻结后才由本地决策工具解盲聚合，没有使用模型评审。

升级的强制条件是：v6.0.5 在共情准确性与证据、温暖感、真人感、继续表达意愿四项上均不劣于 v6.0.4，且同一类严重回归不得在两个独立 case 中复现。

- 决策：`PROMOTE_V605`；`v605_eligible_for_default=true`。

## 解读与限制

本轮结果支持把 v6.0.5 设为默认对话版本，同时保留 v6.0.4 和 v6.0.3 的配置回退。这是合成小样本上的质性非劣门禁，不是心理测量效度、信度、真实被试体验或统计优越性证明。

残余风险包括：个别候选仍可能出现承接后追问的结构感；个别关系修复回合仍可能失败；具体用户对温暖感与访谈深度的偏好仍可能不同。正式发布前仍应完成目标环境冒烟并记录实际 Prompt 版本。
