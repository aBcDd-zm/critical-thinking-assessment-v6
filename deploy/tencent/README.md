# V6 不部署到腾讯云

思衡 V6 是本地自然访谈实验版。此目录只保留一个醒目的拒绝入口，避免从复制的 V5 工作区误用旧域名、Caddy、容器、数据库、备份或凭据。

- 不创建或修改任何云服务器、DNS、TLS、Docker 网络、Caddy、数据库、备份任务或用户账号。
- 不读取、复制、打印或填写生产 `.env`、密钥或管理员口令。
- `deploy.sh` 与 `backup-sqlite.sh` 会以非零状态退出；这属于刻意的安全边界，不是部署故障。
- 若未来需要上线，应从新的评审任务开始，另行设计权限、密钥、备份恢复、真实供应商验收与发布回滚，不可复用 V5 的生产说明。
